# landmarks/

Reserved for future unique/one-off landmark assets — city hall, a stadium,
a signature bridge, etc. Not tied to a zone `type` the way buildings/roads/
parks are (a landmark is a specific instance, not a category every zone of
a type gets), so this will likely need its own manifest keyed by zone `id`
rather than `type` — not built yet, since there's no data to design it
against.

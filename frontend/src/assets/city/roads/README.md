# roads/

Reserved for future road surface/geometry assets (straight segments,
intersections, curves) for a future 3D renderer.

Referenced via `category: "roads"` entries in `../manifest.js`. The current
2D renderer draws roads procedurally (see
`src/renderers/grid2d/RoadTile.jsx`) rather than from an asset file — this
directory is for when that's no longer true.
